## Learning Path

A practical progression for this collection is:

1. Begin with **Dirsearch Deep Dive 2** and **Recursive Hunt** for web discovery.
2. Continue with **Clue Vault** and **ViewSource Vault** to develop web investigation skills.
3. Study **Header Hunt HTTP Clues** for HTTP-level information gathering.
4. Work through **Hash Hunt Beelzebub**, **Hash the Clues**, and **Hash the Hideout** for hash-oriented challenges.
5. Explore **Beacon Base64 Recon** for encoding-related clues.
6. Practice **Beelzebub SSH Deep Dive** for SSH-focused investigation.
7. Finish with **Port Scout Nmap Discovery** and **Netdiscover Recon Relay** for network reconnaissance.

## How to Use the Labs

1. Open a lab using its direct Learn SecByte link.
2. Read the scope and instructions before beginning.
3. Perform all activities only inside the authorized lab environment.
4. Record discoveries, observations, commands, and relevant clues.
5. Try to understand the underlying security concept rather than only completing the challenge.
6. Document lessons learned for future CTF and security exercises.
